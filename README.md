# SocialSpace Phishing-Awareness Demo

A static, GitHub Pages-ready training simulation.

## Behaviour
- Displays a fictional social-media-style sign-in screen.
- First four submissions show an incorrect username/password message.
- Fifth submission shows a welcome page and the awareness lesson.
- Restart resets the demo.

## Privacy and safety
- The page never reads the username or password field values.
- It does not store, transmit, log, or validate credentials.
- It only counts local form submissions.
- Keep the training banner visible and ask participants to use fictional details only.
- This is not affiliated with Facebook or another social-media service.

## Publish using GitHub Pages
1. Extract this ZIP.
2. Create a GitHub repository, e.g. `socialspace-awareness-demo`.
3. Upload `index.html` to the repository's root folder.
4. Go to **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then save.
7. Wait for GitHub Pages to publish; open the URL shown in the Pages section.

Use only fictional usernames and passwords in the exercise.
